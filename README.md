# 加班夜记

一个手绘风的小本子，记录每晚加班：

- 买了什么、花了多少钱（美元）
- Burnout 了几次、身体不行了几次（用「正」字计数）
- 几点下班、备注

带月历视图、本周 / 本月统计、最近 14 晚的花费走势，还有一个**愿望清单**，以及一键生成「我的 N 月加班账单」手绘风分享图（1080×1440，适合小红书）：写下想买的东西和价格，看看加班的零碎花销相当于几晚、够不够买它。

支持**中文 / English** 两种语言，和五种主题：方格本（跟随系统深浅色）、牛皮纸、深夜、樱花、薄荷，在「记录」页最上面的「设置」里切换。

**数据只存在你自己的设备上**，不会上传到任何服务器。可以在「记录」页导出 / 导入备份（夜晚记录和愿望清单都在里面）。

## 安装到手机

打开 App 的网址后：

- **iPhone（Safari）**：点底部的「分享」按钮 → 「添加到主屏幕」
- **安卓（Chrome）**：点右上角 ⋮ → 「添加到主屏幕」或「安装应用」
- **电脑（Chrome / Edge）**：地址栏右侧的安装图标

装好以后，从桌面图标打开是全屏的，断网也能用。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 整个 App（页面、样式、逻辑都在这一个文件里） |
| `manifest.webmanifest` | App 名称、图标、全屏显示设置 |
| `sw.js` | 离线缓存和更新。发布新版本时把里面的 `VERSION` 加一 |
| `icons/` | 桌面图标 |

## 发布（GitHub Pages）

仓库 Settings → Pages → Build and deployment → Source 选 **Deploy from a branch**，
Branch 选 `main`、目录 `/ (root)`，保存。一两分钟后 App 就在
`https://<你的用户名>.github.io/<仓库名>/` 上线了。

## 更新是怎么工作的

- 每次打开或切回 App，它都会检查一次有没有新版本。
- 新版本在后台下载好后，顶部会出现「有新版本了」提示，点「点这里更新」才会切换，不会在你记到一半时突然刷新。
- 更新只替换 App 自己的文件。你的记录和愿望清单存在浏览器的 localStorage 里，更新、清理缓存都不会动它们。
- 「记录」页底部会显示当前版本号，方便确认有没有更新成功。

**注意：** iPhone 上，Safari 里打开的网页和「添加到主屏幕」后的 App 是两份独立的数据，互相看不到。请固定只用桌面图标打开来记录；需要搬数据时用「导出备份 / 导入备份」。

## 备份到 iCloud（免费，点一下）

「记录」页点「备份到 iCloud」→ 在系统菜单里选「存储到文件」→「iCloud 云盘」。
超过 7 天没备份（或记了 3 晚还从没备份过），页面顶部会出现提醒；点「明天再说」会隐藏一天。
换手机恢复：「导入备份」→「浏览」→「iCloud 云盘」，选最新的备份文件，会和手机上已有的记录合并。
